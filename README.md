# 影视 TVBox（video-tvbox）

把 TVBox 生态里的配置接口接进 Folia，做成一个首页整页：浏览、筛选、搜索、详情、播放，播放交给宿主自己的播放器。

- 模组 id：`video-tvbox`
- 适用：Folia `>=0.7.22 <0.8.0`
- 许可：MIT（第三方代码部分见下方「代码来源与致谢」）

## 它做什么

1. **整页工作台**：顶栏注册一个「影视」标签页，海报墙、分类、年份/地区筛选、搜索都在这一页里。
2. **多站点源**：右上角「站点源」可随时切换/粘贴新的配置接口地址，站点列表、分类、筛选条件从配置里动态读取。
3. **详情与播放**：剧集列表、线路切换、清晰度与倍速，播放画面交给 Folia 的播放器呈现。
4. **搜索**：按站点源搜索，结果带源站标签。
5. **可选解析引擎**：配置里 `type 3 / 4` 的 spider 站点需要本地解析引擎才能出结果。引擎**不在本仓库内**、也不随模组分发——只有使用者自己在设置里填了引擎包地址，模组才会去下载解压到本地数据目录。

## 它不做什么

- **不内置任何站点、接口配置或影视内容。** 配置地址由使用者自己填写，站点返回的全部内容与模组本身无关。
- **不内置、不分发解析引擎**（`companion-service.jar` 等）。引擎由使用者自行获取与提供，模组只负责在用户指定地址下载后解压到本地。
- 不收集、不上传任何用户数据；不下载并执行本仓库以外的远程代码（除使用者明确填写的引擎包地址之外）。
- 不做账号体系、不做下载、不做投屏。

## 权限说明

| 权限 | 为什么需要 |
|---|---|
| `net.fetch` | 访问使用者所填配置接口与站点返回的图片/播放地址，没有它浏览和取流都发不出去 |
| `filesystem.data` | 保存站点源地址、引擎路径等本地设置，以及把用户自行提供的解析引擎解压到模组数据目录 |

模组还在 main 侧注册了 `folia-lx://` 协议，用于带防盗链头转发封面图与字节流（只转发使用者请求的 http(s) 地址，不做缓存以外的任何处理）。页面样式通过 `ShadowRoot` 注入，不改宿主全局样式。

## 安装

1. Folia 里开启模组系统
2. 把 `video-tvbox-*.zip` 拖进模组面板，启用时核对签名与上面的权限清单
3. 打开 Folia，顶栏出现「影视」标签页
4. 右上角「站点源」里填你自己的配置接口地址
5. 若你的配置里有 `type 3 / 4` 的 spider 站点，在模组设置里填解析引擎包地址并点安装

## 源码与构建

`app.mjs` 是构建产物（React 界面 + 影视页 + 全部样式打包成一个 ESM 入口）。
源码在 `videoEntry.tsx`（渲染端入口与外壳），需要在 Folia 源码树内构建：放进 `dev/mod-build/`，先跑 `buildModStyles.mjs` 生成 Tailwind 字符串，再用对应版本的 `vite.video.mjs` 打包得到 `app.mjs`。构建依赖 Folia 自身的视频页组件与 `src/mods/folium` 契约类型，因此不单独提供可独立运行的构建脚本。

`index.cjs` + `lib/*.cjs` 是 main 侧入口（配置存储、请求转发、引擎安装、全屏、`folia-lx://` 协议），只依赖 `folium` 契约与 Electron 公开 API。
